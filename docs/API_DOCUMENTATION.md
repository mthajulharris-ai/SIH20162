# SIH 2026 PS 26162 — REST API Documentation

**FastAPI Backend for AI-Based Detection and Classification of Industrial Fires and Persistent Thermal Sources using Satellite Data.**

- **Base URL:** `http://localhost:8000`
- **Interactive Swagger UI:** `http://localhost:8000/docs`
- **ReDoc Documentation:** `http://localhost:8000/redoc`
- **OpenAPI JSON Schema:** `http://localhost:8000/openapi.json`

---

**Error Responses:**
- `422 Unprocessable Content`: Invalid coordinates (`lat > 90`) or invalid brightness (`<= 0`).
- `503 Service Unavailable`: ML model artifact not found on disk.

## 3. Thermal Hotspot Detections

### `GET /api/v1/detections`
Retrieves paginated thermal hotspot records with multi-dimensional filtering.

**Query Parameters:**
| Parameter | Type | Description |
| :--- | :--- | :--- |
| `source` | string | Filter by satellite (`VIIRS_SNPP_NRT`, `MODIS_NRT`, etc.) |
| `predicted_class` | string | Filter by AI class (`Industrial Fire`, `Persistent Thermal Source`, etc.) |
| `min_confidence` | float | Minimum model confidence score (`0.0` to `1.0`) |
| `start_date` | string | Filter `acq_date >= start_date` (`YYYY-MM-DD`) |
| `end_date` | string | Filter `acq_date <= end_date` (`YYYY-MM-DD`) |
| `min_lat`, `max_lat` | float | Southern and Northern latitude boundaries |
| `min_lon`, `max_lon` | float | Western and Eastern longitude boundaries |
| `skip` | integer | Pagination offset (default: `0`) |
| `limit` | integer | Max records to return (default: `50`, max: `1000`) |

**Response `200 OK`:**
```json
{
  "total": 1,
  "page": 1,
  "limit": 50,
  "items": [
    {
      "id": 1,
      "latitude": 21.1702,
      "longitude": 72.8311,
      "brightness": 365.4,
      "confidence": "nominal",
      "acq_date": "2026-09-09",
      "acq_time": "1430",
      "source": "VIIRS_SNPP_NRT",
      "instrument": "VIIRS",
      "frp": 68.5,
      "daynight": "D",
      "predicted_class": "Industrial Fire",
      "prediction_confidence": 0.942,
      "is_persistent": false,
      "created_at": "2026-09-09T09:30:00.000000+00:00"
    }
  ]
}
```

### `GET /api/v1/detections/{id}`
Retrieves a single detection by database ID. Returns `404 Not Found` if missing.

## 4. Incident Alerts & Verification

### `GET /api/v1/alerts`
Retrieves active thermal alerts generated by the automated risk rules.

**Query Parameters:**
- `alert_level`: `CRITICAL`, `HIGH`, `MEDIUM`, `ADVISORY`
- `verification_status`: `REQUIRES_VERIFICATION`, `UNDER_REVIEW`, `VERIFIED`, `DISMISSED`
- `start_date`, `end_date`: Date range filters

**Response `200 OK`:**
```json
{
  "total": 1,
  "unverified_count": 1,
  "critical_count": 1,
  "items": [
    {
      "id": 1,
      "detection_id": 42,
      "alert_level": "CRITICAL",
      "title": "AI-Detected Critical Industrial Fire (Requires Verification)",
      "message": "AI detected high-intensity thermal anomaly predicted as 'Industrial Fire' with 94.2% confidence and FRP 68.5 MW. Requires on-site verification.",
      "predicted_class": "Industrial Fire",
      "confidence": 0.942,
      "verification_status": "REQUIRES_VERIFICATION",
      "verification_notes": null,
      "latitude": 21.1702,
      "longitude": 72.8311,
      "frp": 68.5,
      "brightness": 365.4,
      "acq_date": "2026-09-09",
      "acq_time": "1430",
      "disclaimer": "AI detected thermal signature. Requires ground/field verification.",
      "created_at": "2026-09-09T09:30:00.000000+00:00"
    }
  ]
}
```

### `PATCH /api/v1/alerts/{id}/status`
Updates the operational verification status of an alert.

**Request Body:**
```json
{
  "verification_status": "UNDER_REVIEW",
  "verification_notes": "Operations dispatched local drone verification team."
}
```
